# DSNewLine

**DSNewLine** — российская команда разработчиков программного обеспечения для бизнеса, интернет-провайдеров и образовательных учреждений.

Мы создаём комплексные программные решения для автоматизации рабочих процессов, управления инфраструктурой, обеспечения безопасности и интеграции информационных систем.

## Наши продукты

### DSNewLine CRM
Платформа автоматизации деятельности интернет-провайдеров. Управление клиентами, договорами, заявками, финансами, технической поддержкой и сетевой инфраструктурой.

### DSNewLine Access
Веб-платформа управления системами контроля и управления доступом (СКУД). Централизованное управление сотрудниками, картами доступа, событиями проходов и интеграциями с системой ЭНТ.

### DSNewLine Connect
Нативное приложение для Windows, обеспечивающее защищённое подключение локальной инфраструктуры учреждений к облачным сервисам DSNewLine.

Автоматическая настройка компонентов, мониторинг служб, диагностика, восстановление соединений и обновление программного обеспечения.
